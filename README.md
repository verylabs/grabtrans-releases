# GrabTrans

Translate the text you select anywhere on your Mac — Google Chat, Telegram, Slack, a web page — and reply in the other person's language without leaving the chat.

This repository hosts GrabTrans downloads and its update feed.

## Download

1. Download the latest `GrabTrans-<version>.dmg` from [Releases](https://github.com/verylabs/grabtrans-releases/releases/latest).
2. Open it and drag **GrabTrans** to **Applications**.

Requires macOS 26.4 or later (Apple silicon or Intel). Once installed, GrabTrans checks this repository once a day and offers new versions in the app.
